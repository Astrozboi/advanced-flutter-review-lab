# Flutter Review Lab

Responsive static prototype สำหรับทำแบบทดสอบ Advanced Flutter บนมือถือ แท็บเล็ต และหน้าจอคอมพิวเตอร์

## เปิดใช้งาน

เปิด `index.html` ด้วย browser ได้โดยตรง หรือเสิร์ฟโฟลเดอร์นี้ด้วย static file server ก็ได้ ไม่มี backend และไม่มี dependency ที่ต้องติดตั้ง

## เปิดบนมือถือ/แท็บเล็ตใน Wi‑Fi เดียวกัน

1. เปิด PowerShell ที่โฟลเดอร์นี้
2. รัน `py -m http.server 4173 --bind 0.0.0.0`
3. ดู IPv4 ของคอมพิวเตอร์ด้วย `ipconfig`
4. ให้มือถือ/แท็บเล็ตอยู่ Wi‑Fi เดียวกัน แล้วเปิด `http://<IPv4-ของคอม>:4173`

หน้าเว็บมี breakpoint สำหรับแท็บเล็ตและมือถือ โดยแผงนำทางข้อสอบจะเปลี่ยนเป็นแถบเลื่อนด้านบนเพื่อกดเลือกข้อได้ง่ายบนจอแคบ

## สิ่งที่มีใน prototype

- ชุดทดลอง 20 ข้อ แบบปรนัย 4 ตัวเลือก ครอบคลุมบทที่ 1–10
- แสดงทีละข้อ พร้อมปุ่มก่อนหน้า/ถัดไป และแผนที่ข้อสอบ
- ตรวจคะแนนหลังส่งคำตอบ
- เฉลย คำอธิบาย และเลขหน้าอ้างอิงจาก PDF หลังส่ง
- สรุปหัวข้อที่ผิด และปุ่มทำชุดเดิมใหม่
- โครงสร้าง `examSets` รองรับการเพิ่ม Mock 50 ข้อในอนาคต
