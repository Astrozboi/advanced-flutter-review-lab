# Flutter Review Lab

Responsive static prototype สำหรับทำแบบทดสอบ Advanced Flutter บนมือถือ แท็บเล็ต และหน้าจอคอมพิวเตอร์

## เปิดใช้งาน

[เปิดเว็บแบบทดสอบ](https://astrozboi.github.io/advanced-flutter-review-lab/) จากมือถือหรือแท็บเล็ตได้โดยไม่ต้องเปิดคอมพิวเตอร์

เปิด `index.html` ด้วย browser ได้โดยตรง หรือเสิร์ฟโฟลเดอร์นี้ด้วย static file server ก็ได้ ไม่มี backend และไม่มี dependency ที่ต้องติดตั้ง

## เปิดบนมือถือ/แท็บเล็ตใน Wi‑Fi เดียวกัน

1. เปิด PowerShell ที่โฟลเดอร์นี้
2. รัน `py -m http.server 4173 --bind 0.0.0.0`
3. ดู IPv4 ของคอมพิวเตอร์ด้วย `ipconfig`
4. ให้มือถือ/แท็บเล็ตอยู่ Wi‑Fi เดียวกัน แล้วเปิด `http://<IPv4-ของคอม>:4173`

หน้าเว็บมี breakpoint สำหรับแท็บเล็ตและมือถือ โดยแผงนำทางข้อสอบจะเปลี่ยนเป็นแถบเลื่อนด้านบนเพื่อกดเลือกข้อได้ง่ายบนจอแคบ

## สิ่งที่มีใน prototype

- ชุดทดลอง 20 ข้อ แบบปรนัย 4 ตัวเลือก ครอบคลุมบทที่ 1–10
- Mock สอบจริง 50 ข้อ รวมชุดเดิม 20 ข้อกับโจทย์ใหม่ 30 ข้อ เรียงตามบทที่ 1–10
- แสดงทีละข้อ พร้อมปุ่มก่อนหน้า/ถัดไป และแผนที่ข้อสอบ
- ตรวจคะแนนหลังส่งคำตอบ
- เฉลย คำอธิบาย และเลขหน้าอ้างอิงจาก PDF หลังส่ง
- สรุปหัวข้อที่ผิด และปุ่มทำชุดเดิมใหม่
- เลือก/เพิ่ม/แก้ชื่อผู้ทำก่อนเริ่มสอบ และแยกประวัติผลสอบตามรหัสผู้ทำ
- เปิดผลรอบเก่าพร้อมคำตอบและเฉลยที่บันทึกไว้ตอนส่งข้อสอบ
- โครงสร้าง `examSets` รองรับการเพิ่มชุดข้อสอบในอนาคต

## ชื่อผู้ทำและประวัติ

เพิ่มชื่อเล่นที่หน้าแรก แล้วตรวจชื่อก่อนเริ่มสอบ ผลจะบันทึกเมื่อส่งคำตอบครบ
เมื่อเปลี่ยนผู้ทำ ประวัติจะแสดงเฉพาะชื่อนั้น แก้ชื่อได้โดยประวัติยังผูกกับรหัสเดิม
ถ้าชื่อซ้ำกัน ให้เติมเลขหรือใช้ชื่อเล่นที่ต่างกัน แต่ละผลใช้รหัสและพื้นที่เก็บแยกกันเพื่อลดการเขียนทับเมื่อเปิดหลายแท็บ

ข้อมูลใช้ `localStorage` ในเบราว์เซอร์เครื่องนั้น ไม่ส่งชื่อ คำตอบ หรือคะแนนขึ้น GitHub หรือเซิร์ฟเวอร์ และไม่ซิงก์ข้ามเครื่อง/เบราว์เซอร์
นี่ไม่ใช่ระบบบัญชีหรือการควบคุมสิทธิ์ คนที่ใช้เบราว์เซอร์เดียวกันสลับดูทุกชื่อได้
ล้างข้อมูลเว็บ เปลี่ยนเบราว์เซอร์ หรือปิดโหมดส่วนตัวแล้วประวัติอาจหาย
หากพื้นที่เต็มหรือเบราว์เซอร์ไม่อนุญาตให้บันทึก ระบบจะแจ้งเตือนและเก็บไว้เฉพาะหน้าที่เปิดอยู่ ไม่ลบประวัติเก่าอัตโนมัติ

## เพิ่มหรือแก้ข้อสอบ

แก้ `app.js` บน GitHub แล้ว Commit changes เว็บจะเผยแพร่เวอร์ชันใหม่ผ่าน GitHub Pages
ชุดทดลองอยู่ใน `examSets[0].questions` ส่วนโจทย์เพิ่มเติมของ Mock อยู่ใน `mockExtraQuestions` ระบบรวมเป็น 50 ข้อและเรียงหมายเลขให้เอง
แต่ละข้อมี `chapter`, `topic`, `prompt`, `options` 4 ตัวเลือก, `answer` เป็นลำดับ 0–3, `explanation` และ `source` พร้อมเลขหน้า PDF
